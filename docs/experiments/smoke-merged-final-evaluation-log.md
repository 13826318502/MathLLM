## 3. 四个判错样本分析

### 3.1 正方形坐标题：模型真实错误

模型答案为 `$(14,-16)$`，标准答案为 `$(18,-18)$`。

模型先把正方形顶点计算错了，随后又把点 `(14,-16)` 到原点的距离算成了 `20`。实际上：

```text
14^2 + (-16)^2 = 452
```

而不是 `400`。这属于坐标几何建模和算术复核错误，不是 LaTeX 格式问题。

改进方法：增加中心、边长、顶点、伸缩变换和距离比较的分步训练样本，并要求最终答案前重新计算距离。

### 3.2 无穷等比级数：模型答案正确，评测器误判

模型给出：

```text
\sum_{n=1}^{\infty}\frac{1}{2^n}=1
```

这是正确答案。评测器误判的原因是模型使用了 `**Final Answer:**`，而标准答案是中文说明“级数的和为 1”。当前答案提取和数值比较没有稳定处理带 Markdown 加粗的英文最终答案标记以及公式中的上下文。

改进方法：支持 `**Final Answer:**`、`**Final answer:**` 等标记，并优先提取最终等式右侧的结果 `1`。

### 3.3 未知进制题：模型真实推理错误

模型正确写出了：

```text
AAA_4 = 21A
33_b = 3b + 3
```

但错误地认为只有 `A=3`，并得到答案 `9`。实际上：

```text
21A = 3b + 3
7A = b + 1
b = 7A - 1
```

逐一检查合法数字 `A=1,2,3`：

| A | b | A+b |
|---:|---:|---:|
| 1 | 6 | 7 |
| 2 | 13 | 15 |
| 3 | 20 | 23 |

因此最小值是 `7`。模型的错误是没有枚举所有合法的 `A` 并执行最小值比较，不是 LaTeX 错误。

改进方法：增加未知进制和最值问题训练样本，提示模型在列出方程后枚举所有合法取值，并检查目标函数。

### 3.4 八进制转十进制：模型答案正确，评测器误判

模型答案为 `$25_{10}$`，标准答案为 `$25$`。下标 `_10` 只是说明结果使用十进制，数学答案仍然是 `25`。

这是评测器没有去除十进制标记 `_10` 导致的误判，不是模型数学错误，也不是 LaTeX 错误。

改进方法：答案规范化时将 `$25_{10}$`、`25_{10}` 和 `$25$` 统一为数值 `25`。

## 4. 人工复核后的有效结果

4 个自动判错样本中：

- 2 个是模型真实数学错误：正方形坐标题、未知进制题；
- 2 个是评测器误判：等比级数、八进制转换题。

因此人工复核后的有效准确率为：

```text
8 / 10 = 80%
```

自动准确率 `60%` 目前被答案提取和格式规范化问题低估，不能直接作为模型最终准确率。

## 5. 问题处理优先级

1. 修正评测器对 Markdown 最终答案标记的识别。
2. 修正评测器对 `$25_{10}$` 等十进制下标的规范化。
3. 保留组合数 LaTeX 等价形式的规范化逻辑。
4. 增加坐标几何、最终计算复核和未知进制最值问题的训练数据。
5. 在 system prompt 中保留最终复算和进制按位权展开要求。
6. 使用独立 `test.json` 对基座模型和完整数据训练后的模型进行同条件比较。
