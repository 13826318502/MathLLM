# 概率基础

古典概型：P(A) = A 包含的样本点数 / 样本空间总点数，要求每个基本事件等可能。

条件概率：P(A|B) = P(AB) / P(B)，其中 P(B) > 0。

全概率公式：若 B1 … Bn 构成完备事件组，则 P(A) = Σ P(A|Bi)P(Bi)。

贝叶斯公式：P(Bi|A) = P(A|Bi)P(Bi) / Σ P(A|Bj)P(Bj)。

随机变量的期望与方差：

- 期望 E(X) = Σ x_i p_i
- 方差 D(X) = E(X^2) - [E(X)]^2

二项分布 B(n, p)：E(X) = np，D(X) = np(1 - p)。
