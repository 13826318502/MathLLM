# 常见公式速查

乘法公式：

- 平方差：a^2 - b^2 = (a + b)(a - b)
- 完全平方：(a ± b)^2 = a^2 ± 2ab + b^2
- 立方和：a^3 + b^3 = (a + b)(a^2 - ab + b^2)

数列：

- 等差数列通项 a_n = a_1 + (n - 1)d，前 n 项和 S_n = n(a_1 + a_n) / 2
- 等比数列通项 a_n = a_1 q^(n-1)，前 n 项和 S_n = a_1(1 - q^n) / (1 - q)（q ≠ 1）

三角恒等式：sin^2 x + cos^2 x = 1，sin 2x = 2 sin x cos x。

对数运算：log(ab) = log a + log b，log(a^n) = n log a。
