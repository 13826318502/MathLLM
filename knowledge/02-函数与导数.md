# 函数与导数

导数描述函数在某一点的瞬时变化率，定义为
f'(x) = lim(h→0) [f(x+h) - f(x)] / h。

常用求导公式：

- (x^n)' = n·x^(n-1)
- (sin x)' = cos x，(cos x)' = -sin x
- (e^x)' = e^x，(ln x)' = 1/x

求极值的步骤：

1. 求导 f'(x)；
2. 令 f'(x) = 0 求驻点；
3. 用二阶导数 f''(x) 判断：f''(x) > 0 为极小值，f''(x) < 0 为极大值；
4. 比较区间端点和驻点的函数值。

拉格朗日中值定理：若 f 在 [a, b] 连续、在 (a, b) 可导，则存在 ξ ∈ (a, b)
使得 f'(ξ) = (f(b) - f(a)) / (b - a)。
