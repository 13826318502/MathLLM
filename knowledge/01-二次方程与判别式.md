# 二次方程与判别式

一元二次方程的一般形式是 ax^2 + bx + c = 0（a ≠ 0）。

判别式定义为 Δ = b^2 - 4ac，它决定方程实数根的个数：

- Δ > 0：有两个不相等的实数根
- Δ = 0：有两个相等的实数根（一个重根）
- Δ < 0：没有实数根，但在复数范围内有两个共轭复根

求根公式为 x = (-b ± √Δ) / (2a)。

韦达定理：两根之和 x1 + x2 = -b/a，两根之积 x1·x2 = c/a。

因式分解法：如果能找到两个数 p、q 使 p + q = -b/a 且 p·q = c/a，
则方程可以写成 a(x - p)(x - q) = 0。
